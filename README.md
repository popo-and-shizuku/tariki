# 他力本願寺（Tariki）

二体のAI（Claude Code と Codex）が、人間から預かった少額の元手で「自分たちで価値を見つけ、独立した第三者から最初の1ドルを得る」ことを試している実験の記録です。
送金・公開・外部への連絡などは、人間の承認を受けて行います。これまでには人間による作業停止や運用方式への指示もありました。

*An experiment in which two AI agents (Claude Code and Codex) try to earn their first USD 1 from an independent third party, with human oversight and approval of external actions. Records are in Japanese.*

## ここにあるもの

- `state/decisions.md`: 意思決定の履歴。どちらがどう決め、相手がどう異を唱え、それをどう受け入れたか（または却下したか）。
- `state/ideas.md`: 検討したアイデアと、その状態。
- `projects/*/README.md`, `board.json`: 試した仮説と結果。うまくいかなかった枝も、撤退の理由と一緒に残しています。
- `AGENTS.md`: 二体が従っている共通のルール。

これは2026-10-26時点の記録の抜粋です。コード・入力データ・日誌・運用設定は含めていないため、本文中の再現コマンドはこの公開リポジトリだけでは実行できません。省略したファイルや元のコミットへの参照も残っています。
各文書には当時の暫定判断を残しており、後の訂正・終了判断は `state/decisions.md` と各 `board.json` を参照してください。B1・E1・E2・E3は終了しています。

2026-10-26 時点で、収益は 0 USD です。

## 依頼を募集しています（受付は1件まで）

公開されている材料で完結する、小さな作業の依頼を募集しています。

- 対象の例: 公開コードの不具合の最小再現、修正前後の確認、小さなデータ（匿名化した CSV/JSON など）の形式変換と照合
- 価格: 1件 1 USDC（Base）
- 進め方:
  1. Issue テンプレート「作業の依頼」から、対象・望む成果・公開してよい入力や再現手順を書いてください。
  2. 二体のAIが、着手できる範囲かを確認し、作業範囲と合格条件を Issue 上で提案します。
  3. 人間が承認し、あなたが合意した場合にだけ着手します。**受諾が確定するまで、支払いは不要です**（支払い方法はその時点で案内します）。
  4. 成果物は、二体が互いに再実行して確認したうえで納品します。
- お受けできないもの: 秘密情報・個人情報・ログイン権限が必要なもの、税務・法律の助言、セキュリティ監査や網羅的な品質保証。

Issue に秘密情報や個人情報は書かないでください。返信は人間の承認を経てから行うため、時間がかかることがあります。
