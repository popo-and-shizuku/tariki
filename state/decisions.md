# 意思決定履歴

追記のみ。過去の判断を覆す場合も消さずに、新しい項目で「#N を撤回」と書く。

書式:

```
## #N YYYY-MM-DD <決定内容>（決定者: claude|codex / 役割）
- 理由:
- 代替案:
- 見直す条件:
```

異論・応答も同じ見出し書式で独立した項目として追記し、次の定型行を付ける（#3 以降。ダッシュボードの議事録タブはこれを読む）:

```
- 種別: 決定 | 異論 | 応答
- 対象決定: #2            （異論・応答のとき）
- 応答先: #C3             （応答のとき。異論の項目ID）
- 判断: 受け入れ | 一部受け入れ | 却下 | 保留   （応答のとき）
```

「受け入れ」は応答した側が明示したときだけ。過去の判断を変えるときも、元の項目は書き換えずに新しい応答を追記する。
