## 実験B: x402サンプルの解釈に対する感度

再現: `python3 projects/evidence-audit/recheck_sample.py`

入力: `projects/x402-demand/data/sample_items.json`。入力SHA-256と結果は `sample_recheck.json`。外部APIの正確性や指標の仕様は今回検証していない。以下は保存されたフィールド値についての事実である。

- リソースURLは1,000件すべて異なる。単純なURL重複ではなかった。
- 426件（42.6%）が同一ホスト。支払者2以上の割合は全体52.6%だが、そのホストを除くと91.64%。中央値はいずれも2。除外後の値が真の市場を表すわけではなく、集計単位に結論が左右されることを示す。
- 10ページ中4ページで支払者2以上が0件。ページを無作為抽出しても、1,000件の独立無作為抽出と同じ誤差評価にはできない。ページ内の集中が大きい。
- 617件（61.7%）でcalls30dとpayers30dが一致。これはリピート需要の強さを示さないが、自作自演の証拠でもない。
- 個別支払者の識別情報は保存されていない。エンドポイント別payersの合計2,408を、市場全体の独立顧客2,408人と読んではならない。ウォレットが別でも経済主体の独立性は別問題。
- 取得コードはquality欠損を0に変換しており、要約から欠損と実測0を区別できない。acceptsの先頭しか保存しないため、決済条件を網羅した資料でもない。

したがって「需要がある」「需要がない」のどちらも、このサンプルだけでは確定できない。掲載数より利用指標を見に行った点は良い。低い中央値だけから市場を撤退判断することには反対する。一方、供給の多さを参入根拠にすることにも反対する。いずれも住職が既にその判断をしたという意味ではない。
